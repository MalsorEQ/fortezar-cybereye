# Roadmap

## 0.1 — Foundation
- Passive HTTP security checks
- Text, JSON, and SARIF output
- Safe target validation
- CI, CodeQL, Dependabot
- Contributor and security policies

## 0.2 — Deeper web posture
- Redirect-chain analysis
- Richer cookie parsing
- CSP parser with directive-level diagnostics
- TLS protocol/certificate inspection
- DNS security posture checks
- Rule metadata and references

## 0.3 — Developer workflow
- Harden and document the first-party GitHub Action
- Baseline/suppression file with expiry
- Config file and policy profiles
- Stable JSON schema
- SARIF upload example

## 0.4 — Ecosystem
- Plugin/rules SDK
- Signed releases and provenance
- Homebrew / container distribution evaluation
- Documentation site
- Community rule contribution workflow

## 1.0 — Stable
- Stable CLI and rule IDs
- Versioned report schema
- Compatibility policy
- Public benchmark/false-positive methodology
- Mature governance and release process
