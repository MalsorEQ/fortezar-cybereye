# Governance

ForteZar CyberEye currently uses a maintainer-led governance model.

The primary maintainer is responsible for release integrity, security decisions, rule-quality standards, contributor review, and roadmap stewardship. As the contributor base grows, maintainership may be expanded based on sustained high-quality contributions, review participation, and demonstrated security judgment.

Project decisions should prioritize user safety, transparency, technical quality, interoperability, and long-term community value.
